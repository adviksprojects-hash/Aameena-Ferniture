# Aameena Furniture - Showroom Tablet Auto-Fill Extension

This lightweight Chrome Extension is created specifically for **Aameena Furniture Showroom Tablets / Kiosks** (in Mumbai Bandra, Bengaluru, or Jodhpur).

## How it Works:
1. The customer selects or generates their review on the Aameena Furniture website (`/ai-reviews`).
2. Clicking **"Copy Text & Open Google Reviews Now"** copies the review text to the device clipboard.
3. Google Maps review dialog opens for Place ID `ChIJB1k-wjTbxTsR7dA3i-yPr4Y`.
4. This extension detects the Google Review popup, **automatically pastes the text into the review box**, selects **5 stars**, and focuses the **"Post"** button.
5. The customer only needs to click **Post**!

## How to Install on Showroom Tablet / Chrome:
1. Open Google Chrome on the showroom device.
2. Go to `chrome://extensions/`.
3. Enable **Developer mode** (toggle in the top-right corner).
4. Click **"Load unpacked"** in the top-left corner.
5. Select this folder: `c:\.Decentrax\Aameena-Ferniture\showroom-extension`.
6. That's it! When customer review opens, it will auto-paste without manual typing.
